## Правила параллельной работы

- Потоки независимы, если не пересекаются по площади репозитория: `cf-worker/**`
  и `docs/**` можно вести параллельно, два агента в `cf-worker/src` — нельзя.
- Блокер — это issue с меткой `blocked` и ссылкой на блокирующую задачу.
- Артефакт шага = триггер следующего: PR → review-метка → checks → merge оркестратором
  → закрытие задачи → деплой. Провал любого звена возвращает задачу автору.

## Что НЕ бросать

- **Цель — DSH на Cloudflare + GitHub**, а не собственный харнес с нуля. Скелет —
  только транспорт и лимиты (openspec/changes/walking-skeleton/proposal.md);
  ядро агента, сессии, провайдеры — портируются из DSH в объявленные им швы.
