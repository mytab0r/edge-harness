# Дельта: контракт вердикта AI-ревью — единственность вместо позиции (#1332)

## MODIFIED Requirements

### Requirement: контракт строки вердикта

Второй гейт (`scripts/review/ai_review.py::parse_verdict`) ОБЯЗАН принимать вердикт
по строке `ВЕРДИКТ: approve|rework`, встречающейся в ответе модели РОВНО ОДИН раз.
Позиция строки в ответе значения НЕ имеет.

#### Scenario: вердикт не на последней строке

- **ДАНО** ответ модели, первая строка которого `ВЕРДИКТ: approve`, а далее следует
  содержательный разбор
- **ТОГДА** вердикт разобран как `approve`
- **И** метка PR — `ai:ok`

#### Scenario: два маркера в одном ответе

- **ДАНО** ответ, содержащий и `ВЕРДИКТ: approve`, и `ВЕРДИКТ: rework`
- **ТОГДА** вердикт — `error` (модель противоречит сама себе)
- **И** текст причины называет именно множественность, а не позицию

#### Scenario: маркера нет вовсе

- **ДАНО** ответ модели без строки `ВЕРДИКТ: …`
- **ТОГДА** вердикт — `error`
- **И** решение НЕ выводится из прозы ответа

### Requirement: шапка отказа называет класс

Строка `::error::`, которой гейт сообщает о неудаче, ОБЯЗАНА различать отказ ДО
ответа модели и нарушение контракта ОТВЕТА: лечатся они противоположным (ждать
сброса квоты против починить промпт/парсер).

#### Scenario: цепочка провайдеров исчерпана

- **ДАНО** прогон, в котором ни один провайдер цепочки не ответил
- **ТОГДА** шапка НЕ содержит «ответ не соответствует контракту вердикта»
- **И** называет, что ревью не состоялось — до модели не дошло

#### Scenario: модель ответила, но без маркера

- **ДАНО** ответ модели без строки вердикта
- **ТОГДА** шапка содержит «ответ не соответствует контракту вердикта»
