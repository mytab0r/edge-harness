# Дельта-спека: контракт вердикта AI-ревью — единственность вместо позиции (#1332)

Изменяет сценарий контракта вердикта в дельта-спеке
[`ai-review-gate/specs/journal-tasks-hands/spec.md`](../../ai-review-gate/specs/journal-tasks-hands/spec.md)
(раздел «AI-ревью (второй гейт)») и ADR
[0007](../../../docs/decisions/0007-ai-review-gate.md) п.4 «Контракт вердикта»
(дельта 2026-09-17 записана прямо там). Машина: `scripts/review/ai_review.py`
(`parse_verdict`, `error_headline`).

## MODIFIED: AI-ревью (второй гейт)

~~Сценарий: ответ модели без машиночитаемой последней строки
«ВЕРДИКТ: approve|rework» (нет, две или не последняя) — вердикт `error`,

Сценарий: ответ модели без машиночитаемой строки «ВЕРДИКТ: approve|rework» —
нет вовсе или БОЛЬШЕ одной — вердикт `error`, метка `ai:failed`, публикация
«одобрено» невозможна; двусмысленность никогда не одобряет. Позиция строки
значения НЕ имеет: требование «последняя» при действующей единственности
ничего не снимало, зато отбрасывало корректные вердикты — три из одиннадцати
упавших прогонов за сутки 2026-09-16 отдали `contract_violation` при наличии
корректного маркера не в конце (дословный случай: PR #1328, прогон
35155260819 — `ВЕРДИКТ: approve` первой строкой и следом содержательный
разбор, одобрение выброшено целиком).

Сценарий: вердикт не на последней строке — ДАНО ответ модели, первая строка
которого `ВЕРДИКТ: approve`, а далее содержательный разбор; ТОГДА вердикт
разобран как `approve` (прод-форма покрыта тестом на дословной форме живого
случая, `test_ai_review.py`).

Сценарий: два маркера в одном ответе — ДАНО и `ВЕРДИКТ: approve`, и
`ВЕРДИКТ: rework`; ТОГДА вердикт `error`, текст причины называет именно
множественность (модель противоречит сама себе), а не позицию.

Сценарий: маркера нет вовсе — ДАНО ответ модели без строки `ВЕРДИКТ: …`;
ТОГДА вердикт `error`, решение НЕ выводится из прозы ответа («алерт не
гадает»).

Сценарий: цепочка провайдеров исчерпана — ДАНО прогон, в котором ни один
провайдер цепочки не ответил; ТОГДА строка `::error::` НЕ называет это
нарушением контракта ОТВЕТА: шапка «до модели не дошло», причина класса
«ревью не состоялось — …» (лечится ожиданием сброса квоты, а не правкой
промпта/парсера).

Сценарий: модель ответила, но без маркера — ДАНО ответ модели без строки
вердикта; ТОГДА шапка `::error::` — «ответ не соответствует контракту
вердикта» (лечится правкой промпта/парсера, а не ожиданием квоты).
