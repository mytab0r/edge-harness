# Дельта-спека: журнал (journal-tasks-hands) — наблюдатель за пульсом видит сквозь contract (#133)

## ADDED: Пульс оркестрации (наблюдатель за пульсом планировщика)

34. Watchdog «кто следит за следящим» (`pulse_guard.heartbeat_check`, #120)
    судит о возрасте пульса ТОЛЬКО по прогонам `orchestra.yml`, у которых
    `event` не `pull_request` (`real_orchestra_ticks`). Файл `orchestra.yml`
    несёт job `contract` на каждый `pull_request` — он не имеет отношения к
    пульсу планировщика (job `orchestra`, только `schedule`/
    `workflow_dispatch`) и не должен маскировать его отсутствие частыми
    зелёными прогонами. Выборка для этой сверки — 100 прогонов (потолок
    страницы GitHub), не 5: между двумя настоящими тиками может быть больше
    `contract`-прогонов, чем короткая страница способна прокрутить.
