# Дельта-спека: журнал (journal-tasks-hands) — сигнал дренажа + авто-триаж PR-беклога + карантин задачи (#869)

Реализация (планируется): scheduler.py::drain_gate, авто-диспетч pm-роли,
free_task.py карантин, repo_invariants.py новый инвариант. Пороги — константы
рядом с уже существующими соседями (одно место правды).

## ADDED: Композитный сигнал «время с последнего слияния»

Требование: каждый пульс orchestra, ПОСЛЕ conveyor_gate/wip_gate/mark_conflicts
этого же прогона, drain_gate считает часы с момента max(merged_at) по уже
полученному в этом прогоне списку слитых PR (без нового сетевого вызова).
Открытых PR-кандидатов к слиянию нет — сигнал не тревожит (норма).

Требование: если часы превышают DRAIN_STALL_HOURS, эскалация ПЕРЕЧИСЛЯЕТ все
верные в этом прогоне причины (предохранитель на паузе; WIP-лимит держит
диспатч; конфликтный беклог с исчерпанным бюджетом авто-ребейза; открытый
`contract:failed`) — список фактов, посчитанных другими функциями того же
пульса, не гипотеза и не выбор одной причины. Ни одна из причин не верна —
сигнал так и говорит («причина не установлена по доступным данным»), не
подставляет любую из них по умолчанию.

Требование: маркер тревоги на WATCHDOG_ISSUE (#120) идемпотентен на эпизод —
открывается один раз при первом превышении порога, закрывается при
возвращении часов ниже порога (тот же приём открытия/закрытия эпизода, что
уже применяют WIP_GATE_OPEN_MARKER/WIP_GATE_CLOSE_MARKER).

## ADDED: Автоматический диспетч pm-роли на PR-беклог

Требование: drain_gate в состоянии тревоги дольше PM_DISPATCH_AFTER_HOURS
ИЛИ wip_gate удерживает stuck-эпизод дольше своего порога (#464) —
автоматически, без участия человека, запускается прогон роли `pm` над
текущим открытым PR-беклогом. Один прогон на эпизод (идемпотентность по
маркеру).

Требование: автоматический pm-прогон физически ограничен PM_MAX_CLOSURES_PER_RUN
закрытий — job-обвязка считает факт вызовов `gh issue close`/`gh pr close` за
прогон (не декларацию модели) и красит шаг при превышении. Ограничение,
объявленное только текстом промпта (`~/.claude/agents/pm.md`), для
автоматического (без человека, читающего результат) диспетча недостаточно.

Требование: pm-прогон не закрывает задачу/PR с назначенным исполнителем, с
меткой `waiting:owner`, либо с `blocked` без протухшей по #334/#336 ссылки —
та же граница, что pm.md уже объявляет для ручного вызова.

## ADDED: Карантин задачи, роняющей worker.yml N раз подряд

Требование: задача, чей номер (разобранный из строки лога «Аренда взята:
замок refs/locks/task-N») ассоциирован с QUARANTINE_AFTER подряд фатальными
падениями worker.yml, исключается из `free_task.py::oldest_free`/
`free_candidates` до истечения выдержки. Первая выдержка — PROBE-подобный
backoff (та же форма, что #205, свой маркер на уровне задачи).

Требование: по истечении выдержки задаче даётся ровно одна проба. Успех
(worker.yml завершается не тем же фатальным классом ошибки по этой задаче) —
карантин снимается автоматически, задача снова обычная свободная. Провал —
выдержка растёт (тот же принцип экспоненциального роста с потолком, что
PROBE_BACKOFF_BASE_MINUTES/PROBE_BACKOFF_MAX_MINUTES).

Требование: карантин отличается от ручного `blocked` — не требует
исполнителя и не требует владельца для снятия; эскалация владельцу
происходит только если карантин продлевается дольше отдельно объявленного
верхнего потолка (число не входит в эту дельту, см. design.md «Не
подтверждено»).

## ADDED: Инвариант «дренаж стоял, а сигнала нет»

Требование: `repo_invariants.py` независимо (свой обход слитых PR, свой
обход комментариев WATCHDOG_ISSUE — не через внутреннее состояние
scheduler.py) проверяет: часы с последнего слияния превышают
DRAIN_STALL_HOURS, а среди комментариев WATCHDOG_ISSUE за то же окно нет ни
одного маркера drain_gate. Наблюдательный при внедрении (не в CI_GATING) —
включается в гейт после замера на живом репозитории, тем же порядком, что
инварианты 8/9/10.

## Явно НЕ в этой дельте (см. proposal.md Scope Out)

- Семантическое (не по номеру) сравнение содержимого PR на дублирование —
  делает pm-агент (LLM) с уликой в комментарии, не отдельный
  детерминированный код.
- Admin-merge или любое автоматическое слияние чужого PR без владельца.
- Замена суточного `pipeline-health-self-audit` — работает на другом
  масштабе времени (сутки против часов), сосуществует, не заменяется.
