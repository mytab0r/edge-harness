# worktree-branch-guard: рабочее дерево задачи — инвариант, а не дисциплина

Задача: #332. PR: #333.
Дельта-спека: `specs/journal-tasks-hands/spec.md` — дополнение п.28 «Захват
задачи воркером» инвариантом рабочего дерева.

## Класс закрываемой ошибки

За сутки три инцидента одного класса (контекст #332): агент по задаче #320
правил файлы в дереве оркестратора
(`.claude/worktrees/pr-workflow-sessions-8f1ab5`) на чужой ветке
`agent/258-...`; там же найдены незакоммиченные диффы чужой ветки #297;
главное дерево переключено на чужую ветку из-под работавшего агента.
Дисциплина «не путай деревья» держалась на памяти трижды за сутки — теперь
она enforced механически.

## Решение

1. `.githooks/pre-commit` — гвардия «дерево == задача»: коммит в
   `agent/<N>-*` отклоняется, если имя рабочего дерева (basename top-level
   пути) не начинается с `N-`. Отказ называет ветку, текущее дерево и
   лечащую команду. Пропуск для CI (`GITHUB_ACTIONS=true`, одноразовый
   чекаут воркера называется `edge-harness`) печатает ПРЕДУПРЕЖДЕНИЕ в
   stderr — тихого обхода гвардии нет.
2. `scripts/git/task-branch` вне CI заводит или переиспользует дерево
   `<корень репозитория>/.claude/worktrees/<N>-<slug>` и печатает путь
   агенту — легаси-разнобой имён (`246-lease-claim` на ветке `agent/121-...`,
   `pr-workflow-sessions-8f1ab5` на `agent/323-...`) перестаёт
   воспроизводиться. Повторный вызов на существующую ветку и усыновление
   осиротевшей ветки стоят ДО аренды (класс #360: ничего не захватив,
   ничего не оставляет осиротевшим) и отказывают с командой синхронизации,
   если локальная голова разошлась с `origin/<ветка>` — PR мог подвинуть
   другой канал.
3. Существующие деревья не удаляются и не переименовываются: единственный
   `git worktree prune` вычищает только админ-запись, чей каталог уже стёрт
   с диска, и кричит об этом.

## Доказательство

- `scripts/git/test/worktree-guard.test.sh` — РЕАЛЬНЫЙ файл хука на живых
  git-репозиториях и worktree: совпадение проходит, чужое дерево отклоняется
  с внятным сообщением, вне `agent/*` правило неприменимо. Мутация: снять
  блок гвардии — случай 2 краснеет.
- `scripts/git/test/task-branch.test.sh`, случаи 8–14: заведение дерева,
  переиспользование без дубля, CI-режим, стык «CI-переключение → коммит под
  настоящим хуком», отказ при расхождении с `origin/<ветка>` на путях
  переиспользования и усыновления, свои незапушенные коммиты не отсекаются.
  Мутация: снять `branch_diverged_from_origin` — случаи 12/13 краснеют.

## Газ

Гвардия останавливает только коммит не из своего дерева; возврат движения —
одна команда `scripts/git/task-branch <N>-<slug>`, напечатанная в самом
отказе. Автоматического возврата не нужно: отказ сам называет единственное
лечащее действие, и оно не требует чужих рук.
