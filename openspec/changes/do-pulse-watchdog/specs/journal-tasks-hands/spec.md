# Дельта-спека: журнал (journal-tasks-hands) — сторож живости независимого DO-пульса (#689)

Секция «Пульс оркестрации» домовой спеки (`openspec/specs/journal-tasks-hands.md`)
пополняется несколькими незаархивированными дельтами одновременно (например
`orchestration-pulse-fail-loud`, `pulse-heartbeat-event-filter`, и, если уже
слит, `liveness-watchdog` #519/#522) — номера у них могут временно
пересекаться. Итоговый номер этого пункта присваивается при архивации,
сверяться с доменной спекой на тот момент, не с числом здесь.

## ADDED: Пульс оркестрации (сторож живости независимого DO-пульса, отдельно от событийного канала)

42. Сторож `pulse_guard.independent_pulse_check` — класс, ОБРАТНЫЙ по
    направлению к `event_wake_check` (#510/#519, если уже слит): тот
    проверяет, что событийный будильник (`scripts/gh/wake_orchestra.sh`,
    `triggering_actor.login=github-actions[bot]`) сработал после ревью; этот
    проверяет, что независимый DO-пульс (`cf-worker/src/harness.ts::alarm()`/
    `attemptOrchestraDispatch`, `GH_DISPATCH_TOKEN`, `triggering_actor.login`
    владельца токена) сработал, пока событийный канал маскирует его смерть —
    оба дают один и тот же `event=workflow_dispatch` у `orchestra.yml`,
    различимы только по `triggering_actor.login`.
43. Применимость проверяется ТОЛЬКО когда событийный канал (актор
    `github-actions[bot]`) сам подтверждён свежим — не старше
    `INDEPENDENT_PULSE_STALE_AFTER_MINUTES` (60 минут = 4 такта DO-пульса).
    Честная граница: если оркестратор вообще не диспатчился недавно ни по
    одному каналу, отличить «независимый канал умер» от «PR-активности
    просто нет» по этим данным нельзя — тревога не заводится.
44. Сигнал — тот же канал `escalate()` (комментарий в задачу-статус #120 +
    Telegram), что у остальных сторожей пульса; дедуп — пара маркеров
    (`DO_PULSE_MARKER`/`DO_PULSE_RESUMED_MARKER`, приём `episode_reopened`).
    Текст называет последствие числом часов («независимый пульс не приходил
    N ч, конвейер держится только на событийном канале и встанет, как только
    прекратится активность PR»), не внутреннее состояние счётчика. Если ни
    одного независимого прогона в изученной выборке нет вовсе — текст явно
    помечает возраст как нижнюю границу («как минимум N ч»), не выдаёт
    приближение за точное число.
45. Газ — автоматический: DO-дисптачи возобновились (снова найден прогон
    `orchestra.yml` не от `github-actions[bot]`) — эпизод закрывается тем же
    пульсом, который его обнаружил, без внешнего вмешательства.
