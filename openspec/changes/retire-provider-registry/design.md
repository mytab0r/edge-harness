## Решение: снять, не перебазировать

Варианты: (а) снять плагин; (б) перебазировать на другой namespace; (в) оставить
падающим в карантине. (б) порождает второй namespace правды рядом с апстримным —
класс «два места правды», отклонён. (в) — известный сломанный компонент в
сборке, карантинный шум на каждом деплое, отклонён. Снят — (а).

## Гвардия, которая остаётся

`dsh-edge/verify-provider-namespace.mjs` (литерал `NS$1 = "llm-pi-ai"` в
клиентском бандле) остаётся без изменений: имя namespace по-прежнему зашито в
клиенте литералом, его переименование апстримом обязано ронять деплой громко.
`dsh-edge/verify-catalog-namespace-literal.mjs` — без изменений.

## Доказательство

- Интеграционный чек на собранном артефакте (`registry-integration/check.mjs`)
  — шаг деплоя до выката.
- Прод-канарейка `/api/health` + `settings.describe` + `llm.providers` — шаг
  деплоя после выката.
- Сверка ростеров: скачивание тарболлов релиза деплоем (sha256 в манифесте).
