# Дельта-спека: журнал (journal-tasks-hands) — масштаб находки ревью (#426)

## MODIFIED: Конвейер (оркестратор)

Требование (`openspec/changes/ai-review-gate/specs/journal-tasks-hands/spec.md`):
«ревью-комментарий несет шапку-факты… и канонические блоки предложенных
задач; задачи заводятся в пул одной командой `python scripts/review/file_tasks.py
--pr N` (issue с меткой `task`)» — заменено на:

Ревью-комментарий несёт шапку-факты и канонические блоки предложенных задач,
КАЖДЫЙ блок несёт обязательное второе поле `МАСШТАБ: хвост|отдельно` сразу
после заголовка. `python scripts/review/file_tasks.py --pr N` заводит issue
с меткой `task` ТОЛЬКО по блокам `МАСШТАБ: отдельно` (идемпотентно по
заголовку открытой задачи, как раньше). Блоки `МАСШТАБ: хвост` уходят прозой
в разделе комментария «Доделай в этом PR» — не заводятся issue вовсе, но
содержимое видно автору. Блоки без поля МАСШТАБ не трактуются молча как
«отдельно» (fail loud) — видимы отдельным разделом «⚠️ Без объявленного
МАСШТАБА», issue не заводится, решение вручную.

Сценарий (заменяет прежний): ревью предложило блоки с разными МАСШТАБ →
только «отдельно» заведены issue командой `file_tasks.py`, «хвост» и
безполевые остались прозой в комментарии; повтор команды не создаёт дублей
уже заведённых.
