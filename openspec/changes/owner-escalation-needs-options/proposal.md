# owner-escalation-needs-options: вопрос владельцу уходит только с кнопками

Задача: #1413. PR: #1414. Смежное: [ADR 0014](../../decisions/0014-telegram-inline-buttons.md)
(«Изменение 2026-09-21»), [`docs/agents/PROTOCOL.md`](../../agents/PROTOCOL.md),
«Решение владельца как артефакт».
Дельта-спека: `specs/journal-tasks-hands/spec.md` — модифицирует требование
«отправка кнопочного сообщения», введённое change `telegram-inline-buttons`.

## Класс закрываемой ошибки

Текстовый фолбэк эскалации `waiting:owner` нарушал контракт канала: по задачам
БЕЗ машиночитаемого блока вариантов гвардия слала владельцу «Нужен твой выбор»
с просьбой назвать номер из списка, которого не существует, — а сам алерт это
признавал припиской «(варианты не размечены машиночитаемым блоком)». Живой
случай: 2026-09-14…21 по шести задачам (#1151, #1080, #1036, #1009, #768,
#668) владельцу ушло по восемь таких напоминаний подряд, и он ответил, что не
понял, кто у кого что запросил. Метка при этом держит задачу вне пула —
тормоз, который владелец снять не может: вернуть движение может только агент,
формулирующий варианты, но сигнал адресовался не ему.

## Решение

Адресаты разведены по наличию кнопочных вариантов (`variant_option_labels`
непуст: блок есть И нумерация подряд `1..N`):

- есть — владельцу, с инлайн-кнопками, как прежде;
- нет — владельцу НЕ уходит ничего: громкая строка в прогоне и одноразовая
  (дедуп маркером, ОТДЕЛЬНЫЙ маркер на каждое из двух состояний) пометка в
  самой задаче, адресованная агенту: сформулировать варианты (блока нет) либо
  перенумеровать их подряд (блок есть, нумерация не подряд — состояния
  различает сам код, находка ai-review PR #1414); если решение владельца не
  нужно вовсе — снять метку.

Текстовый фолбэк владельцу убран вовсе: он и был дефектом, а не запасным
путём. Путь ответа владельца («РЕШЕНИЕ: N» комментарием) не менялся — убран
путь вопроса, не путь ответа. Рассмотренная альтернатива «для блока с
непоследовательной нумерацией оставить честный текстовый алерт с перечнем
вариантов» отвергнута: это тот же дефект канала (#1413 требует кнопки, а
кнопки из такого блока не строятся по построению), и состояние чинится
агентом одним механическим шагом.

## Газ

Пометка одноразовая на состояние (маркер `[варианты не сформулированы]` /
`[нумерация вариантов не подряд]`), громкая строка — на каждом проходе, пока
состояние живо. Оба выхода названы в самой пометке и возвращают движение
автоматически: варианты сформулированы/перенумерованы → следующий пульс шлёт
кнопки владельцу; метка снята → задача снова в пуле.
