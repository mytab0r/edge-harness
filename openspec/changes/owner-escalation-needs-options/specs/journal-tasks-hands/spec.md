Требование: эскалация адресуется владельцу ТОЛЬКО при сформулированном
вопросе — машиночитаемый блок «## Варианты владельца» с подряд идущей
нумерацией (`variant_option_labels` непуст) — и всегда с инлайн-кнопками.
Текстового фолбэка владельцу НЕТ: «Нужен твой выбор» без выбора — неправда
(«алерт не гадает») и тормоз, который владелец снять не может. При
несформированном вопросе владельцу не уходит ничего; вместо этого — громкая
строка в прогоне и одноразовая пометка в самой задаче, адресованная агенту.
Состояния «вопроса нет» различает сам код, не читатель (находка ai-review
PR #1414), и у каждого своя пометка со своим маркером дедупа:

- блока нет вовсе (маркер `[варианты не сформулированы]`) — работа агента:
  сформулировать варианты с ценой каждого и разместить блоком;
- блок есть, письменная нумерация не подряд `1..N` (маркер
  `[нумерация вариантов не подряд]`) — работа агента: перенумеровать уже
  сформулированные варианты, не меняя смысла (кнопки из такого блока не
  строятся: клавиатура нумерует позицией в списке).

Обе пометки называют и второй выход: если решение владельца по задаче не
нужно вовсе — снять метку. Пометка одноразовая на состояние (дедуп
маркером); громкая строка печатается на каждом проходе, пока состояние живо.

Требование (не менялось): механизм `escalate(options=None)` в
`pulse_guard.py` сохраняется для будущих вызывающих вне `waiting:owner` —
убран путь ВОПРОСА к владельцу без кнопок, не механизм канала. Путь ОТВЕТА
владельца («РЕШЕНИЕ: N» комментарием, любое число без блока) не менялся.
Позиционная нумерация клавиатуры обязана совпадать с номером, который
владелец видит в тексте и называет в ответе «РЕШЕНИЕ: N» (перенесено без
изменений из прежней редакции — это причина проверки нумерации, не отмена).

Сценарий: задача с телом «## Варианты владельца\n1. Секрет с правами
администратора — …\n2. Оставить ручной инструмент — …» и меткой
`waiting:owner` → пульс `orchestra` шлёт владельцу Telegram-сообщение с
двумя кнопками. Та же задача с телом БЕЗ блока, либо с блоком
«1. … / 3. …» → владельцу не уходит ничего, в отчёте прогона громкая строка
«вопрос не сформулирован», в задаче появляется одноразовая пометка агенту
(своя формулировка и маркер в каждом из двух состояний).
