# Дельта-спека: журнал (journal-tasks-hands) — сторож зомби-прогонов PR-чеков: переэмиссия queued/0-jobs, эскалация рецидива (#1106)

Реализация: `scripts/orchestra/zombie_run_watch.py` (workflow
`.github/workflows/zombie-run-watch.yml`). Пороги и константы — в модуле
(одно место правды, номера строк не фиксируются).

## ADDED: детекция зомби-прогонов и переэмиссия событий PR

Требование: каждый пульс отдельного periodic workflow читает queued
PR-прогоны репозитория одним вызовом; кандидат — прогон старше порога
(`ZOMBIE_AGE_MINUTES`). Кандидат сопоставляется только с ТЕКУЩИМ head
ОТКРЫТОГО PR (ветка и head_sha): устаревший прогон и прогон закрытого/слитого
PR газу не подлежат.

Требование: queued-прогон workflow, чей workflow-файл (версия head_sha
кандидата) объявляет workflow-level `concurrency` без
`cancel-in-progress: true`, газу подлежит только при СВОБОДНОЙ группе того
же workflow (нет ни одного in_progress-прогона): занятая группа — легитимное
ожидание очереди, не зомби. Версией файла считается версия на head, не на
main — PR-локальные правки workflow исполняются на PR.

Требование: зомби подтверждается числом job'ов (`total_count == 0`);
подтверждённый зомби на текущем head открытого PR газится переэмиссией
событий (close→reopen, head SHA не меняется) РОВНО один раз на `head_sha`.
Дедуп-маркер `[zombie-run-watch: переэмиссия <sha8>]` пишется ТОЛЬКО после
успешного действия; чтение маркера фильтрует автора
(`trusted_login=EVENT_ACTOR_LOGIN`), частичная цитата маркера чужим
автором дедупом не является.

Требование: close и reopen выполняются РАЗДЕЛЬНЫМИ вызовами под PAT
владельца (`GH_PIPELINE_PAT`), не `GITHUB_TOKEN` — события от
`GITHUB_TOKEN` не зажигают новые workflow-прогоны (класс #18/#929/#955).
В боевом прогоне (`prod_writes_allowed`) отсутствие PAT — громкий отказ до
действия, не тихий fallback: иначе газ был бы успешным no-op, а дедуп
запер бы сторож навсегда.

Требование: три формы отказа различены и не склеиваются — (а) close не
прошёл: состояние PR не менялось, маркер не пишется, попытка повторяется
следующим пульсом; (б) close прошёл, reopen не прошёл: PR ОСТАЛСЯ ЗАКРЫТЫМ,
эскалация немедленно и без дедупа; (в) газ применён, отчёт не записан: тот
же маркер переэмиссии уходит эскалацией в #120 и становится запасным
носителем дедупа. Отказ эскалации, при котором дедуп-маркер не записан
нигде, красит прогон.

## ADDED: эскалация рецидива и холостой переэмиссии

Требование: после переэмиссии решением о рецидиве участвуют ТОЛЬКО прогоны,
созданные позже неё (`runs_created_after`) — старые permanent-зомби (тот же
run-ID остаётся queued навсегда — подтверждено issue #1106) не создают
ложного «автогаз не сработал».

Требование: подтверждённый рецидив (новый зомби на том же head после
переэмиссии) — эскалация (issue #120 + Telegram) с дедуп-маркером
`[zombie-run-watch: эскалация PR#N@sha8]`, не повторный close→reopen.

Требование: отсутствие НИ ОДНОГО нового прогона на head после переэмиссии
(любого статуса, по id старше прогонов до переэмиссии) — эскалация с
собственным дедуп-маркером `[zombie-run-watch: переэмиссия-без-прогонов
PR#N@sha8]`: газ прошёл вхолостую, повтор бессмысленен, молчаливое «не
трогаю» при стоящем PR запрещено.

Требование: отчёт пульса различает исходы по данным, а не схлопывает их —
«нет кандидатов», «кандидаты вне открытых PR (permanent-зомби)», «ожидание
concurrency-группы», «у прогон(ов) есть job'ы — не зомби», «переэмиссия уже
была, новых зомби нет»; «действий нет» без названной причины — дефект отчёта
(«Алерт не гадает», AGENTS.md).

Требование: цена пульса ограничена — бюджет дорогих /jobs-вызовов за пульс
(`MAX_JOBS_CHECKS_PER_PULSE`) считается ПОСЛЕ сопоставления кандидатов с
открытыми PR и отбраковки ожидания группы; старейшие кандидаты проверяются
первыми; нехватка бюджета переносит остаток на следующий пульс с честным
наблюдением. Сбой первичного чтения (список queued-прогонов) красит прогон;
сбой на одном PR (маркеры, число job'ов, версия workflow-файла, занятость
группы) — ⚠️-наблюдение по этому PR без газа в этом пульсе, прогон не
красится: действие откладывается, а не принимается на непрочитанных данных.
