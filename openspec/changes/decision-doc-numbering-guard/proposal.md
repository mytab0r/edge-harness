## Зачем

Задача: #1078.

Сквозные номера `docs/decisions/NNNN-*.md` (ADR) и `docs/research/NN-*.md` назначаются
вручную, без координации между параллельными PR — тот же класс, что #904 (номера
инвариантов `repo_invariants.py`) и #749 (регистрация гвардий) до его починки.

Живые случаи (не гипотеза):

1. PR #1035 ввёл ADR `0017-stalled-pr-merge-conflict-triage.md`, хотя в `main` номер 0017
   уже занят (`0017-dsh-edge-pr-smoke-local-worker.md`, слит раньше). После кругов
   ai-review файл переименован в `0019`, пропустив `0018` без объяснения.
2. Независимый канал держал незакоммиченный `docs/decisions/0015-parallel-work-on-shared-
   code-boundaries.md` — номер 0015 в `main` занят другим ADR
   (`0015-inbox-dispatch-no-new-secret.md`), а тот же смысл уже слит как `0016-parallel-
   work-on-shared-code-boundaries.md`.

## Решение

Не меняем схему нумерации (сквозная, `NNNN`/`NN` — см. `design.md`, раздел «Отвергнутые
альтернативы» с ценой миграции). Вместо этого:

- Одно место правды для следующего свободного номера —
  `scripts/lib/decision_numbering.py`, читает main И открытые PR (не только локальный
  каталог).
- Гвардия `scripts/ci/guards/decision-doc-numbering-guard.sh` (каталог гвардий, #749 —
  без правки `repo-ci.yml`), красит CI, если один номер занят двумя РАЗНЫМИ файлами —
  и против `main`, и против других открытых PR.
- Не в объёме: #904 (номера инвариантов `repo_invariants.py`) — тот же класс, другой
  носитель (ручные int-константы в одном файле, не каталог пронумерованных файлов),
  уже заведён отдельной задачей.

## Затронутые каналы

Только `scripts/lib/`, `scripts/ci/guards/`. `docs/decisions/`, `docs/research/`,
`docs/INDEX.md` не трогаются этим change (кроме ADR, фиксирующего само решение).
