# Дельта-спека: журнал (journal-tasks-hands) — успех воркера требует доказательства этого прогона (#876)

## MODIFIED: Автономный воркер (конвейер пула)

29.3. Требование 29 (см. `pr-merged-is-success`, requirement 29/29.1/29.2)
    уточняется: «PR по ветке задачи СУЩЕСТВУЕТ» — необходимое, но БОЛЬШЕ НЕ
    достаточное условие успеха. Успех обязан также нести доказательство
    работы, сделанной ИМЕННО в этом прогоне, — конъюнкция трёх фактов:

    - код возврата `dsh` этого прогона равен 0;
    - цепочка провайдеров называет ИМЯ провайдера, ответившего успехом
      (`WORKER_CHAIN_PROVIDER` непуст) — пустой провайдер в тексте отчёта
      об успехе является противоречием самому себе и должен быть невозможен
      по конструкции, единственное место правды —
      `scripts/lib/dsh-ci.sh::dsh_worker_run_is_success`;
    - в ветке задачи появился хотя бы один новый коммит за время этого
      прогона (сравнение отпечатка HEAD до и после запуска `dsh`).

    Предсуществующий PR (открытый или слитый предыдущим прогоном, без
    единого нового коммита и без успешного ответа `dsh` в текущем) успехом
    НЕ является — отчёт о провале различает этот случай («PR существует, но
    не доказывает работу этого прогона») от случая «PR нет вовсе».
