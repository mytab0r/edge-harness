# Задачи: dsh-in-job

Исполнение — через пул Issues (#48). Правила — [PROTOCOL](../../../docs/agents/PROTOCOL.md).

## Слайс 1: задача из морды → сессия DSH в журнале

- [ ] `scripts/hands/dsh_task.sh`: клиент — установка DSH tarball'ами (пины версий
      вверху файла), установка плагинов владельца (suite из `vars.PLUGINS_SUITE_URL`),
      heartbeat-цикл, запуск `dsh --profile headless`, пост событий сессии батчем.
- [ ] `.github/workflows/hands.yml`: `repository_dispatch` (types: `harness-task`) +
      `workflow_dispatch` с вводом текста задачи для отладки; таймаут job'а и
      cleanup воркспейса.
- [ ] Секреты репозитория: `DEEPSEEK_API_KEY` (+ при необходимости
      `DEEPSEEK_BASE_URL`, `DEEPSEEK_MODEL`); токен рук — уже есть (`HANDS_TOKEN`).
- [ ] Прогон: `npm pack` устанавливаемых пакетов на ubuntu-latest — подтвердить или
      опровергнуть резолв транзитивных зависимостей (первый прогон #48).
- [ ] E2E из морды: задача → «руки живы» → разворот сессии в журнале → финальный
      ответ → задача `done`. Провал любого звена виден в морде, не в догадках.
- [ ] Канарейка/дым рук: `workflow_dispatch` прогон с заведомо простой задачей,
      зелёный = «руки живы и ответили».

## Слайс 2 (после слайса 1, отдельная задача)
