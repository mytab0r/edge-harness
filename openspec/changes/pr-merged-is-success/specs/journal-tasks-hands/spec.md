# Дельта-спека: журнал (journal-tasks-hands) — слитый PR тоже успех (#413)

## MODIFIED: Автономный воркер (конвейер пула)

29. Итог запуска воркера оценивается по видимому артефакту, а не по коду
    возврата: PR по ветке задачи СУЩЕСТВУЕТ (открыт с диффом ИЛИ слит) →
    комментарий в задачу (ссылка + хвост отчёта) и Telegram, job зелёный;
    эскалация по playbook (метка `blocked` — то, что есть только у
    владельца) → комментарий и Telegram, job зелёный; иначе (PR нет вовсе,
    закрыт без слияния или открыт без диффа) → комментарий с хвостом лога и
    Telegram, job красный. Все наружные тексты проходят маскирование
    секретов до отправки.

    29.1. Слитый PR — успех БОЛЕЕ полный, чем открытый, не отсутствие
        результата: DSH мог за один вызов довести цикл до мержа (review:ok +
        ai:ok + слияние оркестратором). Единственное место правды на это
        различение — `scripts/lib/pr_outcome.py`.

    29.2. Формулировка отчёта (комментарий в задаче, Telegram — см.
        `telegram-pr-open-merged-reports`, #170) — «PR $verb: …», где `verb`
        — «открыт» или «слит» в зависимости от исхода 29.1, не жёстко
        «открыт».
