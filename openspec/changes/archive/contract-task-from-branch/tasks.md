## Пересмотр 2026-09-06: владелец отменяет декларацию тела как источник

Решение владельца, окончательное: номер задачи PR берётся ТОЛЬКО из имени
ветки; тело PR для этого вопроса не читается вообще. `pr_task_candidates`
(разделы 1-2 выше) снята целиком. Обоснование и развилка — `design.md`,
«Пересмотр 2026-09-06»; заменённый критерий готовности — `proposal.md`,
тот же раздел.

- [x] `task_ref.py`: `resolve_pr_task(pull)` = `task_from_branch(ref)`, без
      `closing_issue`, без `pr_task_candidates`. `declared_tasks`/
      `declares_task` удалены — производственных вызывающих не осталось
      (проверено `grep -rn` по репозиторию).
- [x] `contract_check.py`/`free_task.py::declared_pr_for_task`/

      `extract_task_refs`/`references_task`, это другой вопрос, см. «Явно
