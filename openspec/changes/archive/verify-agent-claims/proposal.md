# verify-agent-claims: машинная проверка заявлений агента о собственной работе (#968)

Задача: #968.

Related: #953 (обёртки без защиты от обхода — тот же род), #893, #905/#906, #964 (живые
случаи заявлений, принятых на слово), [ADR 0026](../../docs/decisions/0026-verify-agent-claims-machine-check.md)
(выбор варианта: машинное исполнение, отказ от критик-прохода, разведение форматов
`MUTATION-PROOF` и PR-блока).

## Зачем

Код агента проходит второй гейт (`ai-review`), а утверждения агента о своей работе
(«доказательство мутацией», «прогнал на истории», «класс закрыт везде») не проверял никто —
оба живых случая (#893, #905/PR #906) пойманы ВРУЧНУЮ чтением отчёта. Заявления читаются
как доказательство, и на них принимается решение о слиянии.

## Что делается

1. Контракт трёх машиночитаемых блоков тела PR — `scripts/lib/mutation_claim.py`:
   «## Доказательство мутацией» (строка «Тест:» + блок ```diff```), «## Класс закрыт»
   (`Grep:` + ожидаемое число совпадений), «## Непроверено машиной» (пометка читателю).
   Прогон мутационного заявления: тест зелёный до → патч накладывается → тест обязан
   покраснеть (иначе `false_claim`) → откат → снова зелёный; вердикт
   `proved`/`false_claim`/`setup_error` с фазами.
2. Живая проверка текущего PR — `scripts/lib/pr_mutation_claim_check.py`, вызов каталогом
   гвардий (#749, `scripts/ci/guards/mutation-claim-guard.sh`): заявление исполняется
   всегда, когда блок заявлен; обязателен блок только для PR, меняющих
   `scripts/ci/guards/*.sh`; непроверяемые формулировки без пометки — `::warning::`.
3. Разведение форматов мутационного доказательства по поверхностям (ADR 0026):
   `MUTATION-PROOF` (ADR 0023) — закоммиченные файлы и исторические ref; PR-блок — тело PR
   и гипотетическое состояние текущего дерева. Парсер распознаёт чужую форму адресной
   ошибкой.

## Чего это не делает

Не проверяет непроверяемое: формулировки вида «прогнал живьём» только помечаются
(«## Непроверено машиной» + `::warning::`), не блокируются — жёсткая блокировка по подстроке
давала бы ложные отказы на честный пересказ чужих инцидентов. Граница и газ тормоза — в
ADR 0026, разделы «Честная граница», «Цена и газ».
