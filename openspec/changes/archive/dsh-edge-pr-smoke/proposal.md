# dsh-edge-pr-smoke: e2e-смоук морды на PR, до мержа

Задача: [#600](https://github.com/mytab0r/edge-harness/issues/600). Решение и
альтернативы — [ADR 0017](../../../docs/decisions/0017-dsh-edge-pr-smoke-local-worker.md).
Дельта-спека: `specs/journal-tasks-hands/spec.md` — новый раздел «PR-гейт
морды dsh-edge (#600)».

## Класс закрываемой ошибки

Регрессия видна только реальным браузером на реальных вкладках Settings, а
код статуса ответа (health-check) её не видит. Владелец нашёл руками четыре
регрессии интерфейса dsh-edge за один апстрим-бамп (удалённый пакет,
изменённый API сессии, коллизия неймспейса локали, коллизия видимой метки
вкладки — issue #518 и смежные); три из четырёх поймал существующий
`dsh-edge/e2e-smoke/smoke.mjs` (issue #502), но ПОСЛЕ деплоя в прод — когда
сломанный интерфейс уже отдаёт трафик. Health-check был зелёным во всех
четырёх случаях.

## Решение

Гоняем ту же проверку (обход вкладок Settings, сбор находок консоли/сети) на
PR, которые трогают состав/сборку морды, ДО мержа — против ЛОКАЛЬНОГО
эфемерного воркера (`unstable_dev`), а не против прода и не через отдельный
preview-деплой на Cloudflare (обоснование выбора — ADR 0017). Логика
обхода вынесена в общий модуль (`browser-walk.mjs`), чтобы прод- и
PR-смоук не расходились в две копии одной проверки.

## Объём

- новый workflow `.github/workflows/dsh-edge-pr-smoke.yml`, триггер
  `pull_request` с путями `dsh-edge/**`;
- новый скрипт `dsh-edge/e2e-smoke/pr-check.mjs` (поднимает собранный
  артефакт локально через `unstable_dev`, с заглушкой журнала);
- рефакторинг `dsh-edge/e2e-smoke/smoke.mjs` в тонкую обёртку над общим
  `dsh-edge/e2e-smoke/browser-walk.mjs`;
- расширение гвардии класса #43 (`scripts/lib/test_dsh_edge_pnpm_guard.py`)
  на новый workflow (тоже ставит пакеты в pnpm-дерево `apps/dsh-edge/
  standalone`).

## Не в объёме

- preview-деплой на Cloudflare (см. ADR 0017, «Главный вопрос»);
- изменения в `deploy-dsh-edge.yml` (риск для боевого пайплайна не оправдан
  этой задачей — дублирование части шагов сборки принято сознательно, см.
  ADR 0017, «Цена»);
- `plugins-src/**` как триггер (см. ADR 0017 и сам workflow — тот же
  аргумент, что у `deploy-dsh-edge.yml`: правка исходника плагина без бампа
  sha256 в манифесте не меняет то, что реально соберётся).
