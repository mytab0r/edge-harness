# Дельта-спека: журнал (journal-tasks-hands) — PR-гейт морды dsh-edge

Расширяет `openspec/specs/journal-tasks-hands.md` новым разделом верхнего
уровня «PR-гейт морды dsh-edge (#600)» (пп. 38–41). Сложен в
базовую спеку одновременно с реализацией (issue #600, ADR 0017).

## ADDED: PR-гейт морды dsh-edge (#600)

Требование: PR, меняющий `dsh-edge/**` (манифест, пин апстрима, патч-серия,
кодогенерация/сборка/гвардия, e2e-смоук), собирает ТОТ ЖЕ артефакт, что
`deploy-dsh-edge.yml` (клон апстрима на пине → патч-серия → плагины по
манифесту со сверкой sha256 → pnpm add → кодогенерация → сборка → гвардия
состава → контракт/детерминизм), и прогоняет на нём e2e generic browser
smoke (`dsh-edge/e2e-smoke/pr-check.mjs`) ДО мержа. Проверка обходит вкладки
Settings структурной эвристикой и собирает находки консоли (console.error,
pageerror) и сети (HTTP-ответ ≥400 после логина); любая находка красит job.
`plugins-src/**` не входит в путь триггера: сборка берёт плагины готовыми
релизами по sha256 из `dsh-edge/plugins.json`, правка исходника плагина без
бампа sha256 не меняет собираемый артефакт.

Требование: проверка гоняется против ЛОКАЛЬНОГО эфемерного воркера
(`unstable_dev`), не против прода и не через отдельный preview-деплой на
Cloudflare — обоснование выбора в ADR 0017. Ни один шаг не обращается к
настоящему Cloudflare API/аккаунту: секреты репозитория (`CLOUDFLARE_API_TOKEN`,
`DSH_EDGE_ACCESS_KEY` и т. п.) не требуются, PR из форка гоняет тот же
пайплайн без единого секрета. Стоимость прогона в чтениях Durable Objects —
0 (локальная эмуляция, не настоящий Cloudflare-аккаунт).

Требование: обход вкладок Settings и сбор находок — ОДНА логика для прод- и
PR-смоука (`dsh-edge/e2e-smoke/browser-walk.mjs`), не две расходящиеся
копии: регрессия, пойманная на одном пути, обязана быть видна и на другом.

Требование: пустой манифест (аварийный npm-префаб маршрут) — e2e-браузерный
шаг PR-гейта пропускается с явным `::notice::` (нет клона и плагинов, из
которых собрать локальный воркер); это не ослабляет прод-гейт — прод-смоук
после реального деплоя (issue #502) гоняется на любом маршруте.

Сценарий: PR правит состав морды под `dsh-edge/**` так, что морда
собирается с коллизией неймспейса локали (класс issue #518; в
мутационной проверке — откат пина плагина в `dsh-edge/plugins.json` на
`plugins-manager-v0.1.6`, до фикса #544, run 34067066688) —
`dsh-edge-pr-smoke` собирает артефакт с правкой, `pr-check.mjs` ловит
исторический console-error бута (`locale namespace "settings.plugins"
already has locale "zh"`): коллизия убивает монтирование шелла, до обхода
вкладок дело не доходит, находка печатается с разделом раннего отказа
(`login`) и boot-состоянием шелла, job красный, PR не сливается по
обычному гейту обязательных проверок.

Сценарий: PR правит только `plugins-src/hello-world/index.ts` (исходник
плагина, `dsh-edge/plugins.json` не тронут) — `dsh-edge-pr-smoke` не
запускается (путь триггера не задет); прогон plugin-forge/smoke-edge-plugins
остаётся отдельным каналом проверки исходника (design.md
`dsh-edge-plugin-system`, не входит в этот PR-гейт).
