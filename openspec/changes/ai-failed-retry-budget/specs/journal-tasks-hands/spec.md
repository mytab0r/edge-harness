# Дельта-спека: журнал (journal-tasks-hands) — бюджет автоповторов ai:failed (#431)

## ADDED: Конвейер (оркестратор)

41. Автоповторы `ai-review.yml` внутри одной эпохи `review:ok`/`review:large`
    (#196) ограничены бюджетом `AI_REVIEW_MAX_ATTEMPTS`, который считается
    только от момента последней простановки метки гейта 1 — маркеры прошлых
    эпох не суммируются с текущей (класс #367/#249: без сброса по эпохе
    несколько пушей запирали PR навсегда).

    41.1. Исчерпание бюджета эскалирует тем же каналом, что предохранитель
        конвейера (#120) — `escalate(repo, WATCHDOG_ISSUE, text)` с
        маркером `AI_REVIEW_EXHAUSTED_MARKER #N`, идемпотентным по
        PR+эпоха (повторно в той же эпохе — молчит).

    41.2. `ai:failed` с фактом `reason: quota_exhausted` (#419) эскалирует
        с первого обнаружения в эпохе, не тратя попытку бюджета вовсе:
        ждать исчерпания квоты провайдера внутри CI бессмысленно, нужен
        человек (сменить провайдера или дождаться сброса квоты).

    41.3. Сбой сверки эскалации (сеть/API) — наблюдение, не действие и не
        повод остановить обход остальных PR.
