# ai-failed-retry-budget: бюджет автоповторов по эпохе + эскалация при исчерпании (#431)

Задача: #431. Дельта-спека:
[specs/journal-tasks-hands/spec.md](specs/journal-tasks-hands/spec.md).

## Зачем

Тормоз без газа (класс #367/#249): `scheduler.trigger_ai_review` считал
маркеры автоповторов (`AI_REVIEW_RETRY_MARKER`) за ВСЮ историю PR, а не за
текущую эпоху `review:ok`. После нескольких пушей на один и тот же PR
исторические маркеры суммировались в общий счётчик, бюджет исчерпывался
навсегда, и PR с `ai:failed` не получал вердикт ничем, кроме ручного
вмешательства владельца, о котором никто не узнавал — сам факт «исчерпан»
попадал только строкой в отчёт оркестратора, а не в канал эскалации.

## Что делается

- Счётчик автоповторов (`ai_review_retry_count`) считает маркеры только
  ПОСЛЕ якоря текущей эпохи (`since=anchor`, момент последней простановки
  метки гейта 1) — маркеры прошлой эпохи не суммируются с текущей.
- Исчерпание бюджета (`attempts >= AI_REVIEW_MAX_ATTEMPTS`) эскалирует тем
  же каналом, что предохранитель конвейера (#120) — `escalate(repo,
  WATCHDOG_ISSUE, text)`, с маркером `AI_REVIEW_EXHAUSTED_MARKER #N`,
  идемпотентным по PR+эпоха (второй раз в той же эпохе — молчим).
- `ai:failed` с фактом `reason: quota_exhausted` (#419) эскалирует С
  ПЕРВОГО обнаружения в эпохе, вообще не тратя попытку бюджета: ждать
  внутри CI бессмысленно (docs/runbooks/switch-llm-provider.md), нужен
  человек — сменить провайдера или дождаться сброса квоты.
- Оба случая различают наблюдение (не удалось сверить эскалацию — сеть/API)
  от действия (эскалация состоялась) по расщеплению #456
  (observations/actions).

## Проверено

- `python -m pytest scripts/orchestra scripts/review scripts/lib -q` —
  зелёные (кроме `test_redact_*`, известный дефект среды Windows, не
  регрессия).
- Мутация: убрать `since=anchor` из `ai_review_retry_count` — тест
  `test_trigger_ai_review_resets_attempt_budget_on_new_epoch` краснеет
  (маркеры двух эпох суммируются, бюджет исчерпан раньше времени).
- Мутация: убрать эскалацию при исчерпании — тест
  `test_trigger_ai_review_stops_after_max_attempts_and_escalates` краснеет.

## Что вне рамок

- Второй машиночитаемый классификатор причины ошибки (`error_reason` в
  `ai_review.py`) остаётся на строковых литералах — отдельная находка,
  не предмет этого изменения.
